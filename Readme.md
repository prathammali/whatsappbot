# WhatsApp Project (Django)

##  Overview
This is a Django project that sends "Hello World" messages to WhatsApp numbers using MeataAPI.
Django (views.py) takes the request and makes an HTTP POST request to the Meta WhatsApp Cloud API.
Meta API processes it and responds with a JSON response confirming that the message (Hello World template) was sent.
Django endpoint returns that JSON back to the browser.

## FLow

Browser → Django → Meta API → Django → Browser
“When I open my Django endpoint in the browser, Django sends a request to the Meta WhatsApp Cloud API. Meta replies with JSON (confirmation of the message delivery), and Django passes that JSON back to the browser. So the JSON I see is not directly from Meta and not generated by Django alone — it’s the Meta API response returned through my Django endpoint.”
